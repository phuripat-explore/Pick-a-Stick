# Pick-a-Stick
a simple studenty picker if the teacher is struggling to pick students to answer questions
A random student picker for the classroom. Type the question, press **Draw a name**,
and a stick with a student's name comes out of the cup.

## Features
- Paste your class list (one name per line, Thai or English)
- No repeats until everyone has answered (can be turned off)
- Optional 30s / 60s answer timer with a beep
- Full screen mode for the projector
- Press Space or Enter to draw
- Class list is saved in the browser, so it's still there next time
